包括的な用語集を作成しました。

| カテゴリー | 用語 | 説明 |
| :--- | :--- | :--- |
| 産業・製造業 | AAS (Asset Administration Shell) | インダストリー4.0における物理的アセットのデジタル表現。サプライチェーン間で安全にデータを交換するためのインターフェースです。 |
| 産業・製造業 | RAMI 4.0 | ドイツのインダストリー4.0プラットフォームが提唱する3次元のリファレンスアーキテクチャモデル。 |
| 産業・製造業 | Submodel (サブモデル) | AAS内で特定の機能や側面（技術データ、エネルギー情報など）の情報を格納するためのモジュール化されたカプセルです。 |
| 産業・製造業 | Digital Nameplate (デジタル銘板) | AASのサブモデルの一つで、メーカー名や製造番号など、物理機器の銘板情報を機械可読な形で標準化したものです。 |
| 産業・製造業 | ECLASS | 産業用の製品データ標準辞書。AAS内でプロパティの意味（セマンティクス）を他のシステムでも一意に解釈できるよう定義するために推奨されています。 |
| 産業・製造業 | IDTA | Industrial Digital Twin Associationの略。AASの規格策定、オープンソース開発、および普及を推進する主要な業界団体です。 |
| スマートビル・不動産 | Brick Schema | ビル設備、空間、センサーなどのデータポイントの関係性を厳密なオントロジーで定義するデータモデル。 |
| スマートビル・不動産 | Project Haystack | ビル設備のメタデータを、テキストタグの組み合わせ（タギング）を用いて直感的に記述・整理する標準化プロジェクト。 |
| スマートビル・不動産 | RealEstateCore (REC) | 不動産運用のビジネスロジックや空間トポロジー、IoTデータを統合するオントロジー。Azure Digital Twinsとの親和性が高いです。 |
| スマートビル・不動産 | BOT (Building Topology Ontology) | W3Cが策定した、敷地、建物、階、部屋といった空間の包含関係のみを記述することに特化した軽量な基盤オントロジーです。 |
| スマートビル・不動産 | ASHRAE 223P | 米国暖房冷凍空調学会（ASHRAE）が策定を進めている次世代のセマンティックモデリング標準。Brick SchemaやHaystackとの調和が図られています。 |
| スマートビル・不動産 | BMS / BAS | Building Management System（ビル管理システム）。空調、照明、防災などのビル設備を統合的に監視・制御するシステムです。 |
| スマートビル・不動産 | BIM (Building Information Modeling) | 建物の物理的・幾何学的な3D構造と属性情報を統合したデジタルモデル。主に設計・建設段階で利用されます。 |
| スマートビル・不動産 | IFC (Industry Foundation Classes) | BIMのデータを異なるベンダーのソフトウェア間で交換・共有するためのオープンな国際標準規格です。 |
| 設備制御・空調 (HVAC) | HVAC | Heating, Ventilation, and Air Conditioning（暖房、換気、および空調）。ビル内の温湿度や空気質を管理するシステム全般を指します。 |
| 設備制御・空調 (HVAC) | AHU (Air Handling Unit) | エアハンドリングユニット。ファン、冷却/加熱コイル、フィルターなどを備え、ビル全体や広域ゾーンに空気を供給する大型空調設備です。 |
| 設備制御・空調 (HVAC) | VAV (Variable Air Volume) | 可変風量制御装置。AHUから送られてきた空気の風量を調整し、各部屋やゾーンごとの温度を制御する末端機器です。 |
| 設備制御・空調 (HVAC) | Chiller (チラー) | 熱源機器の一つ。水などを冷却・加熱し、AHUなどの空調設備に冷水や温水を提供する装置です。 |
| 設備制御・空調 (HVAC) | Boiler (ボイラー) | 水を加熱して温水や蒸気を作り出し、暖房用の熱源として利用する設備です。 |
| 設備制御・空調 (HVAC) | Damper (ダンパー) | 空調ダクト内に設置され、空気の流量を物理的に調節または遮断する可動式の羽根です。 |
| クロスドメイン・IoT | SAREF | ETSI（欧州電気通信標準化機構）が標準化したIoTデバイス向けの参照オントロジー。機能やタスクを定義し相互運用を支援します。 |
| クロスドメイン・IoT | Digital Twin (デジタルツイン) | 物理空間のアセットや建物を、リアルタイムにデジタル空間上に再現した仮想レプリカ。 |
| クロスドメイン・IoT | FDD | Fault Detection and Diagnostics（異常検知と診断）。運用データから設備の故障やエネルギーの無駄を自動的に検知する技術です。 |
| クロスドメイン・IoT | oneM2M | IoTデバイスやアプリケーション間の相互通信を可能にするための国際的な標準規格。SAREFと連携してデータ共有を行います。 |
| 基礎技術・通信 | オントロジー (Ontology) | 特定の領域における知識を、概念のクラス（分類）と関係性として、機械が論理的に推論できる形式で体系化したものです。 |
| 基礎技術・通信 | RDF (Resource Description Framework) | 情報を「主語・述語・目的語」のトリプル（3つ組）で表現するセマンティックウェブの標準グラフデータモデルです。 |
| 基礎技術・通信 | OWL (Web Ontology Language) | RDFを拡張し、クラス階層やプロパティの論理的制約など、より複雑で厳密な意味論を記述するためのオントロジー言語です。 |
| 基礎技術・通信 | Turtle (.ttl) | RDFグラフをプレーンテキストで記述するためのフォーマット。人間にも読みやすく、Brickモデルなどのファイル形式として広く使われます。 |
| 基礎技術・通信 | JSON-LD | Web開発で一般的なJSON形式を拡張し、異なるシステム間でデータの意味（セマンティクス）を共有できるようにしたデータ表現です。 |
| 基礎技術・通信 | DTDL | Digital Twins Definition Language。JSON-LDをベースとし、Azure Digital Twins等でデジタルツインのモデリングに使用される言語です。 |
| 基礎技術・通信 | BACnet | ビルオートメーションシステムのために設計された、ベンダーに依存しない世界的なデータ通信プロトコル規格です。 |
| 基礎技術・通信 | Modbus / LonWorks | BACnetと並び、産業機器やビル設備間でデータ通信を行うために広く利用されている業界標準の通信プロトコルです。 |
